# Matrix Operations Tool

## Project Overview

Matrix Operations Tool is a Python application that uses the NumPy
library to perform common matrix operations.

The user can enter two matrices and perform different operations
through an interactive command-line interface.

## Technologies Used

- Python
- NumPy

## Features

The application supports:

- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Transpose
- Matrix Determinant
